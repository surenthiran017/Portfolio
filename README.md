# Surenthiran V Portfolio

A responsive HTML/CSS/JavaScript portfolio recreated from the structure and information of the deployed portfolio.

## Run
Open `index.html` in a browser, or import the folder into Replit.

## Customize
- Replace `resume.pdf` with your actual resume.
- Update email, LinkedIn and GitHub links in `index.html`.
- Add images under `assets/`.
- Edit colors and layout in `style.css`.
